# Домашнее задание к лабораторной работе № 3

## 1. Условие задачи

### Задание 1

Переменная типа `double` с именем `price` содержит цену товара. Написать выражение для увеличения цены:

- на 12,50 доллара;
- на 25%.

### Задание 2

Создать программу вычисления величины (u) по заданной формуле:

\[
u = \frac{\sqrt[3]{8 + |x-y|^2 + 1}}{x^2+y^2+2} - e^{|x-y|}(\operatorname{tg}^2 z+1)^x
\]

Результат необходимо проверить при заданных исходных значениях. Исходные значения из задания пока не добавлены, поэтому проверочный пример будет внесён после уточнения.

## 2. Алгоритм и блок-схема

### Задание 1

1. Получить исходную цену товара `price`.
2. Для увеличения на 12,50 прибавить к цене 12,50.
3. Для увеличения на 25% умножить цену на 1,25.

### Задание 2

1. Начать выполнение программы.
2. Получить значения переменных `x`, `y` и `z`.
3. Вычислить значение выражения по формуле.
4. Вывести результат.
5. Завершить выполнение программы.

Блок-схему и точные проверки добавлю после уточнения исходных значений из задания.

## 3. Реализация программы

Реализация формулы будет добавлена после уточнения исходных значений и проверки записи формулы по материалам задания.

## 4. Результаты работы программы

Раздел будет дополнен после реализации вычисления формулы и проверки результата на исходных значениях из задания.
