# Домашнее задание к лабораторной работе № 3

## 1. Условие задачи

### Задание 1

Переменная типа `double` с именем `price` содержит цену товара. Написать операторы для увеличения цены:

- на 12,50;
- на 25%.

### Задание 2

Создать программу вычисления величины `u` по заданной формуле:

$$
u = \frac{\sqrt[3]{8 + |x-y|^2 + 1}}{x^2+y^2+2} - e^{|x-y|}\left(\tan^2 z + 1\right)^x
$$

Исходные значения для проверочного примера пока не добавлены. Задание будет дополнено после уточнения данных из методических материалов.

## 2. Алгоритм и блок-схема

### Задание 1

1. Использовать переменную `price`, в которой хранится цена товара.
2. Чтобы увеличить цену на 12,50, прибавить к ней значение `12.50`.
3. Чтобы увеличить цену на 25%, умножить её на `1.25`.

### Задание 2

1. Начать выполнение программы.
2. Получить значения переменных `x`, `y` и `z`.
3. Вычислить значение выражения по формуле.
4. Вывести результат.
5. Завершить выполнение программы.

Блок-схема для второго задания будет добавлена после уточнения исходных данных.

## 3. Реализация программы

### Задание 1

Увеличение цены на 12,50:

```c
price = price + 12.50;
```

Увеличение цены на 25%:

```c
price = price * 1.25;
```

### Задание 2

Реализация вычисления формулы будет добавлена после уточнения исходных значений и проверки записи выражения.

## 4. Результаты работы программы

Для задания 1 проверочные значения зависят от начальной цены товара. Например, если `price = 100.0`, то после увеличения на 12,50 цена составит 112,50, а после увеличения на 25% - 125,00.

Результаты проверки второго задания будут добавлены после реализации вычисления формулы.
